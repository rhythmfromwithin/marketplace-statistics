# Marketplace Statistics Dashboard

Comprehensive data visualizations for major e-commerce platforms.

## Platforms Covered

- **Amazon** - Seller statistics, GMV, regional distribution, million-dollar sellers
- **Shopify** - Store growth, revenue, market share, Shop Pay metrics
- **Etsy** - Seller demographics, revenue trends, buyer behavior, categories
- **eBay** - GMV performance, active buyers, quarterly results, mobile metrics

## Data Sources

- Official company investor relations and earnings reports
- Capital One Shopping
- Printful
- ElectroIQ
- Business of Apps
- Statista
- Etsy Seller Census 2024

## View Online

Visit the live dashboard at: `https://[username].github.io/marketplace-statistics/`

## Local Usage

Open `index.html` in any web browser to view the dashboard locally.
