# 价格情报工具 MVP 需求文档

**版本：** v1.0  
**日期：** 2026-04-16  
**来源依据：** Q2 Navos 产品需求 Part1 + 跨平台产品 API 字段深度对齐调研报告

---

## 一、产品定位

### 核心问题
多渠道卖家无法同时监控 Amazon、eBay、Shopify、Etsy 上竞争对手的定价动态，导致：
- 错过调价时机，被竞品抢走 Buy Box 或流量
- 手动查价耗时，无法规模化监控
- 缺乏数据支撑，调价决策靠直觉

### 产品定义
一款跨平台竞品价格监控工具，帮助卖家追踪竞争对手定价、接收价格变动告警、获取基于市场数据的定价建议。

### 目标用户
- 多渠道卖家（同时运营 2 个以上平台）
- 有明确竞品需要持续监控的中小卖家
- 计划目标用户量：**1000+**

### 差异化定位
现有工具（如 Jungle Scout）仅覆盖 Amazon 单平台。本产品提供跨 Amazon / eBay / Etsy 的统一价格情报视图。

---

## 二、MVP 范围边界

### 做什么（In Scope）
- 跨平台竞品价格查询与展示
- 价格历史快照记录
- 价格变动告警（基于轮询 + 阈值规则）
- 简单定价建议（基于市场最低价 / 中位价 / 最高价区间）

### 不做什么（Out of Scope）
- 自动调价执行（属于智能调价机器人，另立产品）
- 广告费用、物流成本纳入利润计算（属于动态利润计算器）
- 趋势爆款判断（属于爆款商品雷达）
- Shopify 竞品情报（Storefront API 仅返回 storefront 价格，不适合 marketplace 级竞品分析，MVP 阶段排除）

---

## 三、核心功能模块

### 模块 1：竞品价格追踪

**功能描述：**  
用户输入关键词或 ASIN/商品 ID，系统跨平台拉取匹配商品的当前价格，展示在统一列表中。

**字段展示：**
| 字段 | 说明 |
|------|------|
| 平台 | Amazon / eBay / Etsy |
| 商品标题 | 竞品名称 |
| 当前价格 | 含货币单位 |
| 卖家信息 | 卖家名称（可选） |
| 最后更新时间 | 上次轮询时间戳 |
| 商品链接 | 跳转原平台 |

**用户故事：**
> 作为多渠道卖家，我希望输入一个关键词，就能看到 Amazon 和 eBay 上所有竞品的当前价格，而不需要分别打开两个平台手动查找。

---

### 模块 2：价格历史快照

**功能描述：**  
系统按设定频率（默认每 6 小时）轮询并记录竞品价格，用户可查看某商品过去 7 天 / 30 天的价格走势图。

**技术说明（来自 API 调研报告）：**  
> 当前 API 均为查询式，不支持价格变化 Webhook。因此"实时"的实现方式是：**高频轮询 + 历史快照存储 + 告警规则触发**，而非 event-driven 实时推送。

**展示形式：**
- 折线图：时间轴 × 价格
- 支持多竞品叠加对比

---

### 模块 3：价格变动告警

**功能描述：**  
用户为指定竞品设置告警规则，当价格变动超过阈值时，系统发送通知。

**告警规则配置：**
| 规则类型 | 示例 |
|----------|------|
| 绝对值变动 | 价格下降超过 $5 时告警 |
| 百分比变动 | 价格变动超过 10% 时告警 |
| 低于阈值 | 竞品价格低于我的价格时告警 |
| 高于阈值 | 竞品价格高于我的价格时告警 |

**通知方式（MVP）：** 站内通知 + 邮件

**用户故事：**
> 作为卖家，我希望当主要竞品在 Amazon 上降价超过 10% 时，立刻收到通知，这样我可以决定是否跟进调价。

---

### 模块 4：定价建议

**功能描述：**  
基于当前市场价格数据，为用户的商品提供参考定价区间，不自动执行调价。

**建议逻辑（MVP 版本，规则型）：**
- 展示该关键词下：市场最低价 / 中位价 / 最高价
- 标注用户当前价格在市场中的位置（偏高 / 居中 / 偏低）
- 给出简单建议文案，例如："您的价格高于 73% 的竞品，可考虑下调至 $XX–$XX 区间以提升竞争力"

**用户故事：**
> 作为新卖家，我希望系统告诉我同类商品在市场上的价格分布，帮我定一个有竞争力的价格，而不是靠猜。

---

## 四、API 覆盖方案

**整体 API 覆盖度：90%（来源：API 调研报告）**

| 平台 | API | 用途 | 注意事项 |
|------|-----|------|----------|
| Amazon | 商品定价 API (Product Pricing API) | 获取 ASIN 当前价格、Buy Box 价格 | 覆盖最完整 |
| eBay | Browse API | 搜索商品 + 获取价格 | **生产环境需申请审批** |
| Etsy | Open API v3 | 获取 listing 价格 | 字段最简单，接入门槛低 |
| Shopify | Storefront API | ❌ MVP 阶段排除 | 仅返回 storefront 价格，不适合竞品情报 |

**轮询频率建议：**
- 默认：每 6 小时
- 用户可升级至每 1 小时（付费功能预留）

## 六、技术约束与风险

| 风险 | 说明 | 应对方案 |
|------|------|----------|
| eBay Browse API 需审批 | 生产环境使用需申请，有延迟风险 | 优先上线 Amazon + Etsy，eBay 作为第二阶段 |
| 无真实"实时"推送 | 所有平台均为轮询，非 Webhook | 明确产品文案为"近实时"，设置合理轮询间隔 |
| 轮询频率 vs API 限流 | 高频轮询可能触发平台限流 | 实现请求队列 + 指数退避策略 |
| 价格数据准确性 | 平台价格可能含促销、变体差异 | 展示时注明"含/不含促销价"，标注数据来源 |

## 八、MVP 交付范围（分阶段）

### Phase 1（核心可用，4–6 周）
- [ ] Amazon + Etsy 价格查询（关键词搜索）
- [ ] 价格历史快照存储（每 6 小时轮询）
- [ ] 价格走势折线图
- [ ] 基础告警规则（价格变动 % 阈值）+ 邮件通知

### Phase 2（补全平台，2–3 周）
- [ ] eBay Browse API 接入（待审批完成）
- [ ] 多竞品对比视图
- [ ] 定价建议模块（市场价格区间 + 位置标注）

### Phase 3（增长功能，按需）
- [ ] 多关键词批量监控
- [ ] CSV 数据导出
- [ ] 轮询频率升级（付费）
